# Feature status

- `[x]` implemented and verified · `[ ]` not done · ~~struck~~ cancelled/superseded
- A parent is checked only when all of its children are checked.
- Each heading links to the feature page `docs/feat/{name}.md`, which has the full status list (with sub-tasks) and the technical contract.
- The features currently being worked on are listed in [../README.md](../README.md#features-in-development); when one is finished it is removed there and you come back here to pick the next unchecked item.
- This file is regenerated by hand from the feature pages: when you tick a box in a feature page, tick the same line here (top-level lines only are mirrored).
